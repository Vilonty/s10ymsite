S10YM Minecraft Server Website
О проекте
Официальный веб-сайт для Minecraft сервера S10YM (Survival 10 Year Minecraft). Сервер посвящен уникальному эксперименту — 10-летнему выживанию в Minecraft без вайпов карты.

Дата начала проекта: 14/11/2022
Планируемая дата завершения: 14/11/2032

Особенности проекта
Современная архитектура — Пересобранная структура по принципам FSD (Feature-Sliced Design)
Гибкое управление состоянием — Используется Redux Toolkit для эффективной загрузки и кэширования данных
Интерактивный блог — Полнофункциональная система статей с CRUD операциями
Система авторизации — Регистрация и вход с защищенными маршрутами
Адаптивный дизайн — Оптимизирован для всех устройств
Темная тема — Соответствующая стилю Minecraft

Технологический стек
React 18 — Современная библиотека для создания пользовательских интерфейсов

Redux Toolkit — Управление состоянием приложения, загрузка и кэширование данных

React Router 6 — Навигация между страницами

React Hook Form — Управление формами с валидацией

CSS Modules — Изолированные стили для компонентов

Архитектура проекта
Проект построен по принципам Feature-Sliced Design (FSD):

src/
├── app/                 # Инициализация приложения
│   ├── providers/      # Провайдеры контекста (Redux, Auth)
│   └── route/          # Маршрутизация
├── pages/              # Страницы приложения
│   ├── LandingPage/    # Главная страница
│   ├── LoginPage/      # Авторизация
│   ├── RegisterPage/   # Регистрация
│   ├── ProfilePage/    # Личный кабинет
│   ├── BlogPage/       # Блог сервера
│   ├── AboutPage/      # О сервере
│   ├── RulesPage/      # Правила
│   ├── ImportantPage/  # Важная информация
│   └── RequestPage/    # Заявка на вступление
├── widgets/            # Переиспользуемые блоки
│   ├── Header/         # Шапка сайта
│   └── Footer/         # Подвал сайта
├── features/           # Бизнес-функции
│   ├── blog/          # Функциональность блога
│   └── profile/       # Функциональность профиля
├── entities/           # Бизнес-сущности
│   ├── post/          # Сущность поста (API, хуки, store)
│   └── user/          # Сущность пользователя
└── shared/            # Переиспользуемый код
    ├── ui/            # UI компоненты
    ├── style/         # Стили
    └── assets/        # Статические ресурсы
